LingoCraft 🚀

LingoCraft is a lightweight, lightning-fast native macOS desktop application designed for learning English vocabulary, pronunciation, and numbers through interactive mini-games and spaced flashcards.

Built with Tauri v2, HTML5, and Tailwind CSS.

🌟 Key Features

1. 🃏 Smart In-Context Flashcards

Front Face: Displays the target word along with a natural sentence showing the word in context.

Back Face: Clean Russian translation with instant memorization status.

Controls: Smooth 3D flip animation, native voice pronunciation, and keyboard hotkeys (Space to flip, ← / → to navigate).

2. 🔢 Numbers Hub & Game

Comprehensive cheatsheet covering 9 core rules (Base 1–12, -teen vs -ty, hyphenation, hundred/thousand rules, the "S vs no S" trap, ordinals, and year/fraction reading).

Interactive Game Modes:

👂 -teen vs -ty Challenge: Train your ear to distinguish tricky accents (13 vs 30, 15 vs 50).

🔊 Audio Sprint: Listen to compound numbers and pick the correct digits under time pressure.

🎯 Grammar & Reading Test: Spot errors in numbers and years.

3. ⚡ 6 Interactive Training Modes

Pairs Matching: Fast-paced tile-matching game.

4-Choice Quiz: Dual-direction test (EN ➔ RU & RU ➔ EN) with instant mistake highlight and detailed review.

Typing Sprint: Spell words from memory with letter hints.

Context Cloze: Fill missing vocabulary into real-world sentences.

Crossword Blitz: Solve clues and fill in crossword grids.

Mistake Review: Smart replay button focusing strictly on words you answered incorrectly.

4. 📖 Vocabulary Management & Import

Searchable database with filtering by learning progress.

Bulk Import: Add dozens of words at once using simple text formatting (word — translation — context).

Offline First: JSON import/export for full data ownership.

💻 Download & Installation (macOS)

Head to the Releases section.

Download the latest LingoCraft_x.x.x_aarch64.dmg (for Apple Silicon M1/M2/M3/M4) or the Intel DMG.

Open the .dmg file and drag LingoCraft into your Applications folder.

Note for macOS users (First Launch):

Since this app is distributed outside the Mac App Store, right-click (or Control + Click) the app icon on first launch, select Open, and click Open Anyway.

О проекте

LingoCraft — это быстрое и компактное приложение для macOS для прокачки словарного запаса и числительных в английском языке.

Возможности:

Умные карточки с контекстом: вы видите слово сразу в живом предложении.

Тренажёр числительных: карточки правил и аудио-игры на распознавание коварных окончаний (fifteen vs fifty).

6 режимов тренировок: сопоставление пар, тесты с 4 вариантами, спринт по правописанию, вставка в контекст и кроссворды.

Массовый импорт: вставка списков слов в один клик.

Автообновления: при выходе новой версии программа обновляется автоматически.

🛠️ Tech Stack

Framework: Tauri v2 (Rust backend + WebKit frontend)

UI: Vanilla JS + Tailwind CSS

Audio: Web Audio API (Synthesizer & Sound Effects) + SpeechSynthesis API
